# Novelinha Studio IA

Aplicativo local em português para criar roteiros de novelinhas verticais, fichas de personagens, prompts por cena, narração, legendas SRT e vídeos MP4 9:16 para TikTok/Kwai.

O pacote inicial para Windows está disponível como arquivo ZIP nesta conversa. O projeto integra Ollama para roteiro local e ComfyUI para imagens locais; consulte os requisitos e instruções antes de executar.
